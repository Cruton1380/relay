## 📦 NEW OBJECTS (SCHEMAS)

### **1. CommitNode**
Conversation as filament. Each exchange = commit.

### **2. TrainingPack**
Compilation artifact: invariants, decisions, questions, glossary, do-not-do, tasks, citations.

### **3. LogicBranch**
Named cognitive prior/lens. Examples: "Scientific Rigor", "No Metaphor", "Citations Required".

### **4. WeightProfile**
Vector of branch weights. Named bundles: "Scientific Domain", "Legal Conservative", etc.

### **5. InfluenceTrace**
Proof of what influenced output. Active profile, top branches, gate results, violations.

### **6. OutcomeRecord**
Reliability scoring. Tracks: accepted/patched/rejected, patch rate, violation rate.

### **7. Gate**
Hard validator. Examples: "No New Primitives", "Citations Required", "No Semantic Zoom".
