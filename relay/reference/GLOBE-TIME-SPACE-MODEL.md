## 🌍 THE UNIFIED MODEL

**Relay treats Earth as a space-time volume with three navigable axes:**

### **The Three Axes:**

1. **DOWN (Earth Interior)** = Past/History/Reconstruction
   - What already happened
   - What we forgot but can replay
   - Increasingly deep time layers
   - Surgical inspection by day-shells

2. **SURFACE (Earth Crust)** = Current Operations/Now
   - Active coordination
   - Living filaments
   - Current votes/tasks/SCVs
   - The "RTS map"

3. **OUT (Space)** = Unknown/Observable/Exploration
   - What exists but isn't fully understood
   - What we can see but haven't reached
   - Distant knowledge filaments
   - Convergence through evidence

---

## 🔑 CORE PRINCIPLE

**"Time flows from the center outward."**

**What this means:**
- Earth's **core** = Genesis (oldest history)
- Earth's **mantle** = Deep history (months/years)
- Earth's **crust** = Recent history (days/weeks)
- Earth's **surface** = Current operations (now)
- **Space outward** = Unknown future (observable but incomplete)

**Navigation:**
- **Drill down** = Go back in time (replay history)
- **Surface** = Operate in the present
- **Fly out** = Explore the unknown (space)

## 🗳️ VOTES CLARIFIED (FINALLY)

### **Two Distinct Vote Types:**

#### **Type 1: Support Votes (Attention)**

**"I support this direction/policy/plan"**

**Properties:**
- Decaying over time
- Revocable
- Scope-bound (not global)
- Signals commitment/attention

**Use cases:**
- Active proposals
- Current initiatives
- Ongoing projects
- Future plans

**Think:** Delegated influence (existing c8 model)

---

#### **Type 2: Canon Selection Votes (History-Specific)**

**"For coordination purposes, we adopt Branch A as canon"**

**Properties:**
- Selects active interpretation
- Still revocable/decaying (optional)
- Produces clear system default: `activeCanonRef`
- Does NOT erase other branches

**Use cases:**
- Historical disputes
- Scientific models
- Competing interpretations
- Evidence integration

**Critical distinction:**
- **NOT "truth votes"**
- **YES "active working model votes"**

---

### **Why This Matters:**

**Prevents semantic collapse:**
- Support votes ≠ Truth claims
- Canon votes ≠ Permanent truth
- Both are **operational signals**
- Both are **revocable**
- Both are **time-stamped**

**Example:**

**Historical dispute:** "What caused the 2020 coordination failure?"

**Branch A:** Supply chain breakdown  
**Branch B:** Communication failure  
**Branch C:** Authority confusion

**Each branch has:**
- Evidence packs (reports, logs, testimony)
- Models (causal analysis)
- Refs (cross-links)

**Canon vote:**
- "For operational learning, we treat Branch B as active canon"
- Other branches preserved
- If new evidence emerges → Can fork or flip canon

## 📜 RETROACTIVE HISTORY VOTING

### **The Problem:**

**"History was not originally documented during all of history up until now."**

**Most coordination happened without Relay.**  
**Evidence exists but is fragmented.**  
**Interpretations compete.**

---

### **The Solution:**

**Treat history as living governance object.**

### **Process:**

**1. Create History Topic Filament**

```
history.topic.<id>
```

**Example:** `history.topic.french_revolution`

---

**2. Fork When Contested**

**When interpretations diverge:**
- Fork into Branch A, Branch B, etc.
- Each branch is a causal model
- Evidence attaches to branches

---

**3. Attach Evidence Packs**

**Each branch contains:**
- Primary sources (documents, artifacts)
- Secondary analysis (research, models)
- Refs (cross-links to related topics)
- Uncertainty markers (explicit gaps)

---

**4. Run Canon Selection Vote**

**Users vote on:**
- "Which model should Relay use for teaching/coordination?"
- Not "which is absolutely true"
- But "which is best current working model"

---

**5. New Evidence Later?**

**If discovered:**
- Append evidence commits (to existing branch)
- Optionally fork again (if interpretation changes)
- Run new vote (canon can flip)
- Old branches preserved (audit trail)

---

### **Result:**

**History becomes:**
- Living (not frozen)
- Contested (not dogmatic)
- Evidence-based (not authority-based)
- Governable (not unquestionable)

**Without:**
- Rewriting the past
- Hiding disputes
- Pretending certainty
