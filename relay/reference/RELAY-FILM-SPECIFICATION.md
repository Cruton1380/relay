## 🔑 CRITICAL INSIGHT: INTERRUPTIBILITY

**The Missing Primitive (discovered 2026-01-29):**

> "I tried to pause ChatGPT mid-generation and realized it cannot stop. Our SCVs need to be able to do this immediately—just like StarCraft units."

**This is not a UI detail. This is a core control primitive.**

**Every active process must have:**
- ⏸ **HOLD** (pause, preserve state)
- ✋ **STOP** (cancel, mark incomplete)
- 🌱 **FORK** (branch, create alternate)

**The film MUST show this visually, repeatedly, unmistakably.**

## 🎨 VISUAL GRAMMAR (THE LANGUAGE THE FILM TEACHES)

### **Core Elements (Always Consistent)**

**1. HUD (Personal)**
- Top-right: Gauges (capacities + signals)
- Left: Agent roster
- Bottom-center: Build queue
- Matte, clean, operational (never decorative)

**2. Globe (Shared)**
- 3D Earth, smooth physics
- Buildings as solid objects
- Filament arcs (thin, luminous)
- Units moving (drones, agents)
- Zone boundaries (faint, clear)

**3. Filament Chamber (Forensic)**
- Opens when you "dive into" an object
- Timeboxes as discrete blocks
- Chronological (left→right)
- Selectable, zoomable
- Evidence links visible

**4. Control Glyphs (Universal)**
- ⏸ HOLD (always present on active tasks)
- ✋ STOP (always present on active tasks)
- 🌱 FORK (appears when branching possible)
- 🔍 ZOOM (select → hold → zoom into proof)

**5. Zone Transitions**
- Visible boundary (faint line passing)
- Soundscape shifts
- HUD reconfigures subtly
- Rule glyphs appear briefly

## 📐 THE ONE MAGIC MOVE (TEACH EARLY, REPEAT OFTEN)

### **SELECT → HOLD → ZOOM**

**This is the signature interaction.**

**What it looks like:**
1. Cursor selects an object (building, task, SCV, shipment)
2. "HOLD" button latches (visual tether line appears)
3. Camera dives into the object
4. Filament chamber opens
5. Timeboxes appear (commit history)
6. User can inspect proof

**Repeat this pattern 5-7 times across the film.**

**Objects you can do this to:**
- Buildings
- Tasks
- SCVs
- Shipments (drones)
- Votes
- Other people's presence
- Your own identity tree

**Every time, same ritual. The audience learns it subconsciously.**

## 📋 3-ACT STRUCTURE

### **ACT 1: PAIN → ENTRY → LEARN (2-3 minutes)**

#### **Scene 0: Cold Open - The Pain (30-40 seconds)**

**What we see:**
- Fast, stressful montage
- Slack pings, email threads
- "final_v7_REAL.xlsx"
- Jira tickets, calendar conflicts
- Someone asks: "Why is the number different?"
- Reply: "I don't know—maybe the spreadsheet updated"

**Then:** Hard cut to silence.

**Title card:** "Relay: A world where history is visible."

**Why this matters:** Shows the chaos that Relay solves. Makes the "why" land before the "how."

---

#### **Scene 1: Enter Relay (30 seconds)**

**Authentication (silent, instant)**
- Device recognized
- Identity filament tree loads
- HUD fades in

**HUD appears:**
- Gauges live
- Agent roster visible
- Build queue present
- Globe centered

**First caption:** "This isn't an app. This is a world."

---

#### **Scene 2: The Magic Move (30 seconds)**

**Teach: SELECT → HOLD → ZOOM**

**User clicks a building.**
- Building highlights
- "HOLD" button appears, clicks
- Camera dives
- Filament chamber opens
- Timeboxes appear

**Caption:** "Every object has history. Select, hold, zoom."

**User backs out. Repeat with a task.**

**Audience learns: This is the pattern.**

---

### **ACT 2: POWER → USE → CONTROL (3-4 minutes)**

#### **Scene 3: Task + SCV Delegation (60 seconds)**

**Build queue shows a task.**

**User clicks task → Opens panel**

**Actions:**
- Delegate to SCV
- Configure (read-only, time-limited)
- Approve execution contract

**SCV works. User does other things.**

**Then: USER PAUSES THE SCV MID-EXECUTION**

**Critical moment:**
- User clicks ⏸ HOLD
- SCV freezes instantly
- HUD: "Execution paused—state preserved"
- User inspects partial results
- Decides: Continue, Fork, or Stop
- Chooses Continue

**Caption:** "Nothing runs past your consent."

**Why critical:** This teaches interruptibility. The missing primitive.

---

#### **Scene 4: Shopping as Production (60-90 seconds)**

**User spins globe, zooms to iStore.**

**Clicks building → Catalog appears**

**Selects MacBook Pro:**
- Production time: 15 minutes
- Escrow: $2,800 locks
- Delivery: Drone express

**Confirms order.**

**Build queue updates:** Progress bar filling

**On globe:** Drone spawns, route appears, drone moves

**User clicks drone:** Custody chain visible, ETA shown

**Caption:** "Logistics is units you can see."

---

#### **Scene 5: Zone Boundary Crossing (30 seconds)**

**User walks from café to office.**

**Visual:**
- Boundary line passes under camera
- Soundscape shifts
- HUD reconfigures subtly
- Small rule glyphs appear: "Professional conduct zone"

**Caption:** "Place changes rules. Zones are constraint geometry."

**Why critical:** Teaches that rules are spatial, not social.

---

#### **Scene 6: Voting + Delegation (45 seconds)**

**HUD pulses: Vote ending soon**

**User clicks vote:**
- Proposal shown
- Options visible
- User's influence: Delegated to expert
- Expert's reasoning visible
- Evidence links present

**User could revoke. Chooses not to.**

**Caption:** "Voting is force lending, not ballots. You can revoke anytime."

**Why critical:** Teaches authority is temporary, scoped, revocable.

---

#### **Scene 7: The Refusal Scene (30 seconds)**

**User tries to:**
- Access someone else's private work (no permission)
- OR override a vote without authority
- OR inspect evidence they don't have rights to

**System calmly refuses:**

**Message:** "You don't have authority in this context."

**No error dialog. No shame. Just clarity.**

**Caption:** "There is no admin mode. Power is scoped."

**Why critical:** Shows what Relay won't do. Prevents future builders from adding superuser hacks.

---

#### **Scene 8: Crisis/Proof Moment (60-90 seconds)**

**Finance forecast SCV completes analysis.**

**User inspects (SELECT → HOLD → ZOOM):**

**Filament chamber opens:**
- Commits visible as timeboxes
- User clicks commit 44 (forecast formulas)
- Risk: Growth assumption (15%) exceeds historical (11%)

**User:** "This is too optimistic."

**User clicks 🌱 FORK**

**Two branches now exist:**
- Original (optimistic)
- Conservative (forked)

**User approves conservative branch.**

**Escrow adjusts. Build queue updates.**

**Caption:** "Errors are first-class. Repair ≠ erasure."

**Why critical:** Shows history is navigable, forkable, not destructive.

---

#### **Scene 9: Drone Arrives (20 seconds)**

**Drone reaches destination.**

**Delivery confirmed.**

**Automatic:**
- Escrow releases
- Task closes
- Filament seals
- Build queue clears

**Quiet closure. No fireworks.**

**Caption:** "Clean closure. History preserved."

---

### **ACT 3: MEANING → CLOSURE → META (1-2 minutes)**

#### **Scene 10: Rewind Scene (30 seconds)**

**User discovers a small error in earlier work.**

**User:**
- Scrubs backward on filament
- Sees exact commit where mistake entered
- Forks from before the mistake
- Both branches exist

**No deletion. No panic.**

**Caption:** "History is append-only. All branches visible."

**Why critical:** Teaches that time is navigable but immutable.

---

#### **Scene 11: Closing Meta-Shot (20-30 seconds)**

**Camera zooms out from the globe.**

**Further out:**
- See the film itself
- See the docs
- See the architecture commits
- See the filaments

**All the same structure, different scales.**

**Final caption:**

**"Once the rules are visible, the system builds itself."**

**Fade to Relay logo.**

**Why critical:** Encodes the self-teaching property. Makes the film itself a genesis artifact.

## 🎯 EXECUTION CONTRACT SCENE (CRITICAL)

**This must appear before Scene 3 completes.**

**When user delegates to SCV:**

**Panel appears:**

**Execution Contract**

**What it will do:**
- Analyze Q1 forecast for risk factors

**What it will NOT do:**
- Modify forecast
- Commit changes without approval
- Access private data

**Authority scope:** Read-only  
**Time limit:** 30 minutes  
**Stop conditions:** User can pause/stop anytime  
**Evidence required:** Citations for all claims

**User approves.**

**Caption:** "Understanding precedes execution."

**Why critical:** Shows nothing "just happens." This is Relay physics, not UX.

## 🔍 WHAT THE FILM REFUSES TO SHOW

**To teach Relay correctly, the film must conspicuously NOT show:**

❌ **Dashboards** (only HUD + Globe + Filament chambers)  
❌ **Feeds** (no infinite scroll, no notifications)  
❌ **Global scores** (no reputation numbers)  
❌ **Copy/paste** (only select→hold→bind)  
❌ **Hidden authority** (all decisions explicit)  
❌ **Forced actions** (always voluntary)  
❌ **Mutable history** (only append, fork, seal)  
❌ **Autoplay** (everything requires consent)

**If the audience never sees these, they won't invent them when rebuilding.**

## 🎨 SOUND DESIGN RULES

### **Each System Has a Sound:**

**HUD:**
- Soft mechanical clicks
- No pings, no alerts (except time pressure pulses)
- Capacities sound different from signals

**Globe:**
- Ambient hum (coordination active)
- Buildings emit subtle tones (different per type)
- Drones have engine sounds (deterministic, not varied)

**Filament Chamber:**
- Timeboxes "snap" into place
- Zoom has a whoosh (diving into proof)
- Evidence links click when followed

**Zone Transitions:**
- Soundscape shifts (café → office distinct)
- Boundary crossing has a gentle tone

**SCVs:**
- Working: soft processing sound
- Paused: sound stops (teaches interruptibility)
- Completed: clean completion tone

**Control Actions:**
- HOLD: latch click
- STOP: clean cut (no error sound)
- FORK: branch sound (splitting, not breaking)

**Rule:** No dramatic music. Only diegetic sound (sounds that "exist" in the world).

### **Production Pipeline (Per Training Unit)**

**1. Extract from Film**
- Identify relevant scene(s)
- Extract keyframes
- Document timing/pacing

**2. Generate Graphics-Only**
- Pure visuals
- Motion design
- No narration, no text paragraphs

**3. Generate AI Avatar Placeholder**
- AI-generated narration (temp)
- AI avatar performs
- Demonstrates timing/framing

**4. Record Human Narrator**
- Creator replaces AI narration
- Timing locked to graphics
- Swappable without breaking sync

**5. Create Hybrid Version**
- Graphics + narration + minimal labels
- Captions (SRT/VTT)
- Accessibility optimized

**6. Validate**
- STOP/HOLD/FORK functional
- No new semantics introduced
- All modes teach same invariants

**7. Bind to Object**
- Training pack attached
- Available on HOLD
- Ready for in-system use
