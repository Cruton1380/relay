## 📋 CRITICAL UNDERSTANDING REQUIRED

### **1. Help = HUD (Not External Docs)**

**In Relay, there is NO:**
- Separate help center
- External documentation site
- Tutorial flow outside the system
- "Read the docs" redirect

**Help manifests as:**
- In-world HUD layer
- Always instantly available
- On any surface, object, panel, tool, generator
- Governed by STOP/HOLD/FORK primitives

**Help is not UI chrome. Help is control physics.**

---

### **2. The Film Decomposes into Training Units**

**The Relay movie is NOT just a marketing video.**

**It is:**
- A training source
- Decomposed into micro-training units
- Bound to every object that needs explanation
- Available in 3 modalities (graphics-only, narrated, hybrid)

**Every scene in the film → Multiple training packs for objects shown**

---

### **3. The HUD Character is a Swappable Skin**

**The creator (human narrator) appears as an avatar.**

**But critically:**
- Avatar is NOT required
- Avatar is NOT authority
- Avatar is a themeable, replaceable template

**Users can choose:**
- Creator avatar (default)
- HUD-only (no character)
- Alternate character templates
- Silent mode (graphics-only)
- Subtitles-only
- Any combination

**The narration track is swappable without changing explanation structure.**

---

### **4. Relay is an IDE + Generator Platform**

**Relay is NOT "an app with features."**

**Relay is:**
- IDE for coordination physics
- Movie generator
- Image generator
- Code editor
- Simulation engine
- Globe world interface
- All tools integrated

**Every surface must have HUD training built in.**

**No exceptions.**

---

### **5. Themes are First-Class Filaments**

**Themes are NOT just colors.**

**A theme is a lens bundle:**
- HUD visual style
- Character template (avatar)
- Explanation mode defaults
- Accessibility presets
- Visual grammar mappings (semantic tags → materials)

**Themes are projection, not truth.**

**Invariant:** If a theme changes meaning, it is invalid.

---

### **6. Theme Marketplace (Build/Trade/Use)**

**Themes are distributed through Relay's own mechanisms:**

**Users can:**
- Install
- Fork
- Remix
- Merge
- Vote on adoption
- Rate reliability

**Governance:**
- Themes scoped: personal, project, org, global
- Safety rules enforced (themes cannot lie)
- Enterprise controls available

## ⚠️ CRITICAL RULES (NON-NEGOTIABLE)

### **1. Help is Physics, Not UX**

**All training units must obey:**
- ⏸ HOLD = freeze state + enter explain mode
- ✋ STOP = cancel + mark incomplete
- 🌱 FORK = branch explanation path

**If an explanation cannot be paused, forked, or replayed → INVALID**

---

### **2. No New Semantics**

**All three explanation modes (graphics, narrated, hybrid) must:**
- Teach the same invariants
- Reference the same objects
- Demonstrate the same physics
- Result in the same understanding

**If modes teach different things → INVALID**

---

### **3. Themes Cannot Lie**

**Themes must NOT be able to:**
- Hide refs
- Obscure authority chains
- Remove audit views
- Suppress refusal states
- Reduce conflict legibility
- Fake legitimacy signals
- Hide time pressure
- Obscure zone boundaries

**If a theme violates any safety rule → Dangerous modification or INVALID**

---

### **4. Film is Source of Truth for Training**

**No training unit may:**
- Contradict the film
- Exceed the film's physics
- Introduce concepts not in film or architecture

**If ambiguity exists:**
1. Film invariant wins
2. Architecture wins over projection
3. Silence is preferable to speculation

---

### **5. Every Surface Has Training**

**No exceptions. If a surface exists, it must be explainable in-place.**

**Surfaces include:**
- IDE/editor
- Movie/image generators
- Simulation/replay (forensic chamber)
- Globe world
- SCV/task orchestration
- Voting/governance
- Merge/conflict panels
- Resource gauges
- Theme marketplace
- ...and all others

---

### **6. Narrator is Swappable**

**The human creator is canonical narrator (default).**

**But:**
- AI avatars allowed as placeholders
- Demonstrate timing/framing for human re-recording
- Words are replaceable
- Structure/timing are NOT

**System must function:**
- With narration
- Without narration
- With replaced narration

**No explanation may rely on personality, tone, or persuasion.**
